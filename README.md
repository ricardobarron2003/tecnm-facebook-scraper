# TecNM Facebook Scraper & Chatbot

Proyecto para extraer publicaciones de Facebook del TecNM León y generar un chatbot interactivo.

## Funcionalidades

- Scraping automático de publicaciones
- Almacenamiento en archivo de texto
- Chatbot con búsqueda semántica
- Actualización periódica

## Instalación

1. Instalar dependencias:
```bash
pip install -r requirements.txt
```

2. Configurar credenciales en `config.ini`

3. Ejecutar:
```bash
python src/chatbot.py
```
